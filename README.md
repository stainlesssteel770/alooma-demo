# Alooma Demo (sandbox)

A per-device demo of the Alooma warehouse packing helper.

- Open the Pages link and use every feature with no sign-in.
- Changes save only in this browser (localStorage) and never touch
  the live warehouse data or the live repo.
- Each visitor has their own sandbox; visitors do not see each other's edits.
- Reset button in the banner clears the demo and reloads the sample stock.
- This copy is a snapshot of main. To sync app updates here, re-run
  build_demo.py + push_demo.py from the main workspace.
