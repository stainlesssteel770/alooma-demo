How to make a token (one time, ~2 minutes)
  1. On github.com, click your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it "Alooma editor", set an expiration you're comfortable with.
  3. Repository access: Only select repositories → pick alooma.
  4. Permissions → Repository permissions → Contents → Read and write. Leave everything else off.
  5. Generate, copy the token, and paste it here. It is saved only on this device — never in the repo, never on the site.

Disconnecting removes the saved token from this device only. The site goes back to view-only here; your data in the repo is untouched.

Default boxes

When an order's craft and kit count exactly match a rule, Packing shows which boxes to use — and prints them on the packing sheet. Off by default; rules are saved in the shared data, so every device sees the same ones.

Your boxes

Rules

Bin locations

Each item's shelf bin — shown on the pack list, the packing sheet and the count sheet, and used by the "By bin" sort. Off by default. To set one: Inventory → tap the item → Bin.

Reorder

When an item is at or under its low-stock warning level it appears on the Inventory tab's Reorder list. The quantity below is the default order amount for every low item — change any number on the list before printing.

With quantities hidden, the printed list shows only the craft name and the items to reorder — no on-hand, warning-level, or order numbers.

Bulk tab

Bulk records orders packed outside the app. Off by default — turn it on to show the Bulk tab.

Names

Saved on this device. Printed sheets use the Packed-by name and count sheets the Counted-by name; History shows who packed or counted each order.

Recipes

Edit what goes in each craft. Changes save right away and sync like everything else. A hidden craft stays out of the Pack and Bulk pickers but queued orders for it still finish. Renaming a craft never changes old History entries.

About

Data lives in data.json in the public GitHub repo stainlesssteel770/alooma. Every edit commits a new version of that file through the GitHub API, so any device opening this page sees the current status. Viewers need no sign-in. There is no access code.
